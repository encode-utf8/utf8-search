> 分支 `feat/docs-site-20261003`（基于 main `a586ac6`）；**未合并 main**。

## 3. 部署与回滚（待拍板，本轮未部署）

上线（只新增 docs 容器 + 优雅重载 Caddy，**不重建/不重启 app 与 searxng**）：

```bash
docker compose up -d docs                                  # 首次拉起静态站（bind mount）
docker compose exec -T caddy caddy reload --config /etc/caddy/Caddyfile   # 优雅重载，不断连接
curl -sI http://127.0.0.1:8080/ | head -1                  # 期望 200
curl -sI https://43.106.104.49.sslip.io/guide/ | head -1   # 期望 200（经 Caddy）
```

回滚：

```bash
docker compose rm -sf docs                                 # 停并删除说明站容器
git checkout -- Caddyfile && docker compose exec -T caddy caddy reload --config /etc/caddy/Caddyfile
```

说明：站点内容更新 = 重新生成 `docs/site/index.html` 即可（bind mount 即改即生效，无需重启容器）；
`docs` 服务不参与搜索链路，异常不影响 app/searxng。

## 4. 已知限制（如实）

* 搜索是**子串匹配**（无分词/拼音/模糊），页面规模（5 页）下足够；后续如需增强再评估；
* 站点内容来自仓库现有文档的**渲染快照**：源文档变更后必须重新生成（`--check`/单测会拦住过期提交）；
* 站点暂不收录 `docs/reports/**` 的过程报告全文（只链接稳定文档与报告索引），避免把内部实验数据暴露给使用者；
* 本轮**未部署**：`/guide` 在合并 + 上述两条命令执行前不可访问。
