## 4. 已知限制（如实）

* 搜索是**子串匹配**（无分词/拼音/模糊），页面规模（5 页）下足够；后续如需增强再评估；
* 站点内容来自仓库现有文档的**渲染快照**：源文档变更后必须重新生成（`--check`/单测会拦住过期提交）；
* 站点暂不收录 `docs/reports/**` 的过程报告全文（只链接稳定文档与报告索引），避免把内部实验数据暴露给使用者；
* **已部署（2026-10-03）**：`/guide` 已可公网访问；回滚步骤见 §3，`docs` 异常不影响 search 链路。

## 5. 追加：左侧目录分点（2026-10-03）

按使用反馈，左侧导航从「只有页面」升级为「**分组 → 页面 → 分点目录**」：

* 每页的 `h2/h3` 章节全部列出（共 **92 条** 目录项，5 页），缩进区分层级；
* **仅当前页展开**（`.nav-page.active .toc`），避免 5 页目录同时铺满侧栏；
* 点击目录项 = 页内深链（`#page-…--…`），可复制 URL 直达；滚动时用 `IntersectionObserver` 高亮当前小节；
* 生成器 `scripts/build_docs_site.py` 输出 TOC，单测新增断言（`toc-link` > 50、`nav-page.active` 存在）；
* **已即时生效**（bind mount，无需重启容器）：公网 `https://43.106.104.49.sslip.io/guide/` → 200，
  页面含 **92 条 `toc-link`**（与生成物一致）；`build --check` OK、离线 **388 passed / 4 deselected**、`check_refs` 0 违规。
