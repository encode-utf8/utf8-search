## 2. 第 1 步：Q1 三类坏形态的修复

统一判据 `off_topic_form(result, query)`（与 `is_aggregator_page` / `is_offtopic_index_page` 同源）：
**形态命中 + 主题针对性** —— 形态由标题/内容特征判定（**不维护站点黑名单**）；
「主题针对性」用查询侧闸门实现：查询本身就在找这类内容时不生效；
电视/院校两类还要求**正文无实质内容**（避免误伤长篇节目文稿、校园新闻稿）。

| 形态 | 判据 | Q1 的三条实例 | 单测 |
| --- | --- | --- | --- |
| 电视/节目单页 | `《节目名》+播出日期` / 节目单 / 节目预告 / 第 N 集（**刻意不含"第 N 期/完整版"**——那是周报/系列文章写法） | 央视《生活圈》 20260929 | 命中剔除；查询含「节目/视频」时不生效；**回归**：`AI 周报（第3期）` 不受影响（修掉一次误伤，见 §3） |
| 院校迎新/开学页 | 迎新/开学/新生/入学/招生/报到… + 正文为空 | 仁川机场院校「2026年9月学期新生迎新」 | 命中剔除；长文校园新闻（含"开学"）不误伤 |
| 开运日历/黄历页 | 开运/開運/黄历/吉日/占卜/运势/风水/星座… | 日本「2026年9月の開運日カレンダー」 | 命中剔除；查询含「开运/吉日」时不生效 |

接入 `apply_rank_filters` 的 `offtopic_form` 步骤（候选不足可补回；新闻路径不受影响，与聚合页共用开关）。

## 3. 过程记录：一次误伤与修正

第一版电视判据把「第 N 期」也算作节目单形态 → 立刻被既有回归测试抓住：
`tests/test_pipeline.py::test_news_topic_keeps_aggregator_pages_general_drops_them` 里的
「最近一周 AI 行业动态（第N期）」周报被误判为电视节目页。
**修正**：电视形态只保留 `《…》+日期` / 节目单 / 节目预告 / 片花 / 第 N 集 —— 不含「第 N 期 / 完整版」。
该回归测试现已全绿（这也是本轮唯一一次被判据抓回来的误伤）。
