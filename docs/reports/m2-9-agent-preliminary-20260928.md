## 5. 局限与缓解（LLM 判官风险）

| 风险 | 说明 | 本轮缓解 |
| --- | --- | --- |
| **判官自我偏好 / 过宽** | LLM 判官倾向把"话题相同"当成"相关"（例如把栏目页、汇总页判为相关） | ①**校准集先行**（10 条历史 ❌ 必须全 0，否则作废）；②**盲评**（去掉池标签/URL）；③**强制三档 + 一句依据**，不允许只给 0/1；④**全部「勉强相关」交用户裁决** |
| **单一判官（无交叉验证）** | 没有第二个判官做一致性检验 | 把 15 条「勉强」全部暴露给用户抽检；未达标项与历史 ❌ 名单**高度一致**（Q2/Q16 历史也❌），可作外部一致性证据 |
| **判官见过带标签文件** | 本 agent 在上一轮核对产物时已看过 `m6-pool-ab-detail-20260928.md`（含池 24/40 标签） | 正式判分使用的是**去标签判官单**；且被评对象只有池 24 一列、不存在 A/B 选择问题；该残留风险已在此披露 |
| **覆盖度不等于质量** | 有些「明显相关」是同一篇文章的多站转载（如 Q8 的 #3/#4） | 计入相关（相关性与重复度是两个维度）；重复问题由 5.3 的同站/多样性过滤处理 |
